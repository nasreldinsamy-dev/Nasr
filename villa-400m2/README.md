# منزل سكني بشقتين — أرض 400 م² — نسبة إشغال 60%

رسومات معمارية ابتدائية لمنزل من دورين (شقة لكل دور) بمدخل أمامي وسلم خلفي،
كل شقة بها 3 غرف نوم وصالة وحمامان ومطبخ، جميعها بإضاءة وتهوية طبيعية.

## المخرجات

| الملف | الوصف |
|---|---|
| `الرسومات-المعمارية-منزل-400م2.pdf` | كل اللوحات الست مجمعة — مقاس A3 أفقي |
| `التقرير-التصميمي.md` | التقرير الكامل: المساحات، مطابقة الكود، النظام الإنشائي |
| `drawings/*.svg` | اللوحات منفردة بصيغة متجهية (قابلة للطباعة بأي مقاس) |
| `preview/*.png` | صور سريعة للاستعراض |
| `generate_plans.py` | الكود الذي يولّد اللوحات (تعديل الأبعاد يعيد إنتاج الرسم) |

## اللوحات

1. الموقع العام والارتدادات — 1:150
2. مسقط الدور الأرضي — 1:100
3. مسقط الدور الأول — 1:100
4. قطاع رأسي أ-أ — 1:75
5. الواجهة الأمامية — 1:75
6. مسقط السطح — 1:100

## إعادة التوليد

```bash
python3 generate_plans.py      # ينتج drawings/*.svg
```

ثوابت التصميم (أبعاد الأرض، الارتدادات، أبعاد الفراغات) في أعلى قسم
«بيانات المشروع الهندسية» داخل `generate_plans.py`.

> **تنبيه:** رسم ابتدائي (تصميمي) — لا يصلح للتنفيذ أو الترخيص قبل اعتماده من
> مهندس نقابي ومراجعته مع الإدارة الهندسية واشتراطات البناء بالمنطقة.
